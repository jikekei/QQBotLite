# 验证记录

日期：2026-10-04。测试在 Windows x64 本机执行；QQ 接口为本地模拟，游戏操作为模拟接口。

已验证：

- LabAPI 1.1.7 DLL、EXILED 9.14.2 DLL 均用本机实际游戏 / 框架引用程序集编译成功，无警告和错误。
- Go vet 通过；权限、指令语法、群过滤、重复消息、空服 / 断线、Token / 握手、请求超时均有测试。
- NapCat 正向 WebSocket、群身份补查、消息段和 CQ 文本、发送拒绝与取消连接。
- 官方身份规范化、UTF-8 拆分、被动回复次数、主动消息无事件 ID、拒绝发送不重试、Webhook 验证挑战及 Ed25519 事件验签。
- 官方 WebSocket 网关 Identify、心跳 ACK、会话 Resume 与失效后重置。
- 生产 C# 网络 / 调度代码通过真实 WebSocket 与 Go 桥接通信；验证游戏操作主线程、所有操作、重复请求只踢一次、未知操作拒绝、求助冷却与重启先回复后执行。

- 独立 EXE 首次中文引导生成配置与独立 Token、输出插件 YAML、配置检查、之后无输入启动且不改原 Token。
- 完整 `模拟 QQ → 独立 EXE → C# 插件` 链路：查询、角色统计、玩家列表、成员拒绝管理、群主管理、重复 QQ 指令不重复执行、删除的指令不回应。

本轮共 17 项顶层 Go 测试通过，含表驱动子项、实际 C# 插件桥接及独立 EXE 集成测试。独立 EXE 为 7.45 MiB；连接模拟 QQ 和插件并执行上述指令后的工作集测得约 11.49 MiB。此数值仅为本机此次测试，不含 NapCat 与游戏服务器进程，也不是固定内存承诺。

发布文件包含独立 EXE 与两套 DLL，不含开发工具、数据库、游戏 / 框架原始 DLL 或真实账号配置。
